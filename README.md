Student Management System

A beginner-friendly Python project that manages student records using an SQLite database.

Features

* Add new students and their subject scores
* View all student records
* Search students by ID or name
* Update student details
* Delete student records with confirmation
* Generate student reports with average scores and grades
* Identify top-performing students, including ties
* Store records persistently using SQLite
* Validate user input to prevent invalid entries

Technologies Used

* Python
* SQLite
* SQL
* VS Code

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

python main.py

The database and required table are created automatically when the program runs.
